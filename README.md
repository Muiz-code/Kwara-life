# Naija Votes
A multiplayer Nigerian life sim: live as a citizen in your state and LGA, get your PVC, campaign, and vote once on
a shared election day. Grew out of Kwara Life, which lives on as the hand-built Ilorin map.

A game. Not affiliated with INEC. Not a poll or prediction.

See CLAUDE.md for the plan and rules, docs/DESIGN.md for the design and docs/DECISIONS.md for later decisions.
Prototypes: reference/naija-votes-2027.html and reference/kwara-life.html (open in a browser).

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # sim and data tests
```
